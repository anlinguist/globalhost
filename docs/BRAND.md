# Brand: G.Host

> Status: chosen by the owner, 2026-10-30. Covers the Phase 3 app and its agent; nothing in Phase 1–2 depends on it.

## Name

**G.Host** is the app and the chat agent the owner talks to. Write it with the capital G, the period, and the capital H. The factory itself, the repo, the CLI, package names and domains stay `globalhost`. The GitHub App identity (`globalhost-ai`) is the factory's bot and doesn't change.

## Mark

A draped bedsheet ghost: a round head, sides that flare out as they fall, a soft uneven hem, and two matching eyes.

| File | Use |
|---|---|
| `brand/g-host-mark.svg` | The mark on its own, ink on transparent. Eyes are holes, so it works on any ground. |
| `brand/g-host-icon.svg` | App icon: paper ghost on an ink rounded square. The PWA's manifest icons (192, 512, maskable, apple-touch 180) are rendered from this at build time. |
| `brand/favicon.svg` | Browser tab. Slightly larger eyes for 16 px, and it switches to paper in dark mode. |
| `brand/g-host-mark-glance.svg` | Alternate kept for later: the same ghost glancing to the side, for an "agent is looking at something" state. Not in use. |

**Keep it draped.** A flat-sided body with even, regular scallops is the arcade (Pac-Man) ghost, and a rounded blob with oval eyes is close to other software marks. Edits to the mark shouldn't drift toward either.

Don't redraw the mark freehand. Change the SVGs, and re-render the icons from them.

## Color

| Token | Value | Use |
|---|---|---|
| ink | `#14161F` | Mark on light, icon ground, text |
| paper | `#F3F1EC` | Mark on dark, page ground |
| accent | `#6B5CF5` | The period in the wordmark; interactive accents. Provisional. |

## Wordmark

"G.Host" set in Space Grotesk Bold, tight tracking (−0.02em), with the period in the accent color. In a lockup, the mark sits to the left at about the cap height plus a third.
